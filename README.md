## About me

I'm **Aftab Ufaq** (also known as Aftab Amin), a senior software engineer from Islamabad, Pakistan, who builds complete mobile products: **React Native apps for iOS and Android** and the **Node.js services behind them**. Since 2020 I have shipped **15+ apps to the App Store and Google Play** across e-commerce, fintech, VPN, caller ID, family safety and AI, and designed the REST and real-time APIs, databases and cloud infrastructure they run on (NestJS, Express, MySQL, MongoDB, Redis, Socket.IO, AWS, Firebase).

Today I work as a Senior Full Stack Developer at **Zoobi Apps & Games Technologies** (Islamabad) and remotely for **Vendo** (Berlin). My recent focus is **AI application engineering**: turning LLM and generative-media APIs (OpenAI, Google Gemini, Anthropic Claude, FLUX, on-device llama.cpp) into reliable production features with provider fallback chains, strict output schemas, quota and cost control, and privacy by design.

Most of my work lives in private client repositories, so the store links and project notes below are the public trail. I'm open to **senior React Native, full-stack, Node.js backend and AI application engineer roles**, remote or with relocation.

## How I work

- **Ship the whole feature.** From the React Native screen to the Node.js endpoint, the database migration and the server it runs on.
- **Make APIs easy to consume.** Every backend ships with OpenAPI docs, a Postman collection and integration guides for Android, iOS and React Native developers.
- **Design for cost and privacy.** Quota ledgers and provider fallbacks keep third-party bills at zero; user location never reaches an LLM.
- **Test what matters.** End-to-end suites on disposable databases (144 tests on the latest service) and live-API tests for AI integrations.
- **Use AI tooling seriously.** Claude Code with project rules, memory files and test gates: the navigation backend went from spec to production in nine days.
